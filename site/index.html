Plugins & Native UI

两层插件能力，业务代码不用分叉

Host 插件与桌面保持同一套规则；需要原生体验时，再用 SDK 加一层原生界面。

Host 插件：与桌面同一套

插件继续运行在真实 DSH Host 中，通过官方 slot 注册 UI。手机端把核心 slot 映射为 Compose 组件，Web 界面跑在 Web 岛。

  • 安装 / 启停 / 卸载与桌面一致
  • client-slots 注册直接复用
  • Web 岛与原生组件混合渲染

伴生原生 UI：Kotlin + Compose

以 APK 形式分发原生界面，通过 DSH Native UI SDK 注册到右侧栏、设置页、输入栏等落点。

// 注册右侧栏开始页的一枚入口胶囊
class MyGuide : SlotContribution() {
  override val slot = NativeSlot.RIGHT_PANEL_GUIDE_ENTRY
  override val guideTitle = "我的面板"
  override val guideDescription = "原生 Compose 页面"
  @Composable override fun Render(...) { ... }
}

Architecture

手机本地，真实运行

内置 Debian 用户空间与 Node 运行时，启动上游 DSH；所有请求都在设备内完成。

本机 Host

  • Debian (glibc) + proot 用户空间
  • Node 24 + 上游 @deepseek-ai/dsh
  • 本地 loopback Web GUI 与 bridge 设备能力
  • Host 入口预打包，冷启动约 15.6s

Android 客户端

  • Kotlin + Jetpack Compose 原生界面
  • 真实工作区直连手机共享存储
  • Remote / bridge 双通道，插件 UI 不丢
  • MIT 风格开放仓库，可自行构建
